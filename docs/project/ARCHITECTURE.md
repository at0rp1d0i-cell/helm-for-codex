# Architecture

## Layers

- Lead layer
- Ops layer
- Worker layer

## Modules

- canonical docs
- skills
- ops templates
- review packets
- review results
- review passes
- repo checks

## Constraints

- single visible lead
- small active concurrency
- repo as memory
- structured review-result capture is the preferred live review path
- deterministic fallback remains available when live subagent review is unavailable
