# Code Of Conduct

## Our Standard

Participate with respect, clarity, and technical honesty.

Examples of expected behavior:

- critique ideas, not people
- explain tradeoffs concretely
- keep disagreement factual and specific
- help make the project more understandable for the next contributor

Examples of unacceptable behavior:

- harassment or personal attacks
- insulting or dismissive language
- repeated bad-faith review behavior
- publishing private information without permission

## Scope

This applies to project discussions, issues, pull requests, reviews, and other project spaces.

## Maintainer Enforcement

Maintainers may edit, remove, or close content that violates this code of conduct.
